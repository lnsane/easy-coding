# easyCode v0.1.1

> AI 配置对齐 PI-Desktop：预设列表、字段结构与其 `provider-presets.ts` / provider config schema 保持一致，补齐 Kimi 等全部预设。
> 日期：2026-09-23

## 变更背景

v0.1.0 的 Provider 预设只有 5 个（OpenAI / Anthropic / DeepSeek / Gemini / 自定义），用户对比 PI-Desktop 后发现缺少 Kimi 等大量预设，要求"添加 AI"的设置与 PI-Desktop 一模一样。

## 本版本变更

### 1. Provider 预设与 PI-Desktop 完全一致（23 个）

新增 `src/shared/provider-presets.ts`，逐条对齐 PI-Desktop `packages/shared/src/provider-presets.ts` 的 `NAMED_ENDPOINT_PRESETS`（id / vendorKey / name / baseUrl / apiStyle / aliases / zhipuCompat）：

- 国际：OpenAI、Anthropic、Google Gemini、OpenRouter、Groq、xAI、Mistral、Together AI、Fireworks、OpenCode Go
- Z.AI 系：Z.AI、Z.AI Coding Plan
- 国内：DeepSeek、Alibaba (China)（通义/dashscope）、**Moonshot AI (China)**、Zhipu AI、Zhipu AI Coding Plan、SiliconFlow (China)、Volcengine Ark（豆包）、MiniMax、MiniMax (OpenAI)、Xiaomi、**Kimi For Coding**
- 另加「自定义（OpenAI 兼容）」入口（对应 PI-Desktop 的 custom 类型）

每个预设自动带出：vendorKey、Base URL、API 样式。

### 2. 表单字段对齐 PI-Desktop 添加对话框

字段与其"添加提供程序"对话框一致：**名称、端点（Base URL）、API 样式、模型 ID、API Key**，另加"启用"开关（对齐其 `enabled` 字段）。

- 新增 **API 样式**下拉：auto / chat_completions / responses / anthropic_messages / google_generative_ai / opencode_go（取值来自其 provider config schema）
- 选预设自动填充 Base URL + API 样式；名称为空时自动跟随预设名
- 模型 ID 改为手动输入（PI-Desktop 走 models.dev 目录发现模型，本应用暂不引入该目录）

### 3. 数据结构与迁移

`ai_configs` 表新增 3 列（对齐其 provider record 的 `vendorKey` / `apiStyle` / `enabled`）：

| 新列 | 默认 | 说明 |
| --- | --- | --- |
| `vendor_key` | `''` | 老数据自动回填为 provider 列的值 |
| `api_style` | `'auto'` | API 样式 |
| `enabled` | `1` | 启用开关 |

迁移在 `initDb()` 内自动执行（`PRAGMA table_info` 检测缺列后 `ALTER TABLE` 补列），老库无需手工处理，已实测迁移成功。

### 4. 界面细节

- 配置管理列表新增「已停用」徽标（enabled = false 时显示）
- 配置类型 `AIConfig` / `AIConfigInput` 同步增加 vendorKey / apiStyle / enabled

## 验证

- 实机启动：v0.1.0 老库自动迁移，表结构变为 12 列
