# 编排功能完善：支持 Markdown 文档编排

## 背景与目标

完善编排功能，使其支持在编排流程中对 Markdown 文档进行开发。

## 功能点

### 1. 编排中的角色配置

在编排中选择一个角色，并针对该角色完成以下配置：

- **职责**：该角色在编排中承担的具体职责。
- **职位**：该角色对应的职位。
- **提示词**：该角色使用的提示词。

### 2. Markdown 编辑器的执行入口

在 Markdown 编辑器上方新增一个按钮，用于执行编排任务。

## 交互流程

1. 在编排中选择一个角色，并为其配置职责、职位与提示词。
2. 在 Markdown 编辑器中打开文档。
3. 点击编辑器上方的按钮，触发编排任务执行。
4. 编排任务基于 Markdown 文档执行（文档在流程中的具体作用见「待确认」）。

## 待确认

以下内容在原需求中未明确，开发前需确认：

- 编排中选定的角色与 Markdown 文档之间的关系：是文档级绑定，还是在执行时选择。
- 执行编排任务时，Markdown 文档是作为任务输入，还是作为任务执行的目标对象（即由编排对文档进行开发）。
- 执行结果是否回写到当前 Markdown 文档中。

## 验收标准

- 编排中可选择角色，并可为该角色配置职责、职位与提示词。
- Markdown 编辑器上方存在执行编排任务的按钮。
- 点击该按钮可触发编排任务执行。
