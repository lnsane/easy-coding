# 编排功能完善：支持对 Markdown 文档进行编排

## 背景与目标

完善编排功能，使其支持在编排中对 Markdown 文档进行开发。

## 功能点

### 1. 编排中的角色配置

在编排中支持选择一个角色，并针对该角色完成以下配置：

- **职责**：定义该角色在编排中承担的具体职责
- **职位**：定义该角色的职位
- **提示词**：为该角色设置具体的提示词

### 2. Markdown 编辑器的执行入口

在 Markdown 编辑器上方新增一个按钮，用于执行编排任务。

## 交互流程

1. 在编排中选择一个角色，并定义其职责、职位与提示词。
2. 在 Markdown 编辑器中打开文档。
3. 点击编辑器上方的按钮，执行编排任务。
4. 编排任务通过 Markdown 文档执行。
