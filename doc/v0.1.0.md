# easyCode v0.1.0

> 首个版本：完成应用骨架、AI 配置引导与持久化、主页面框架、Windows 打包。
> 日期：2026-09-23

## 本版本内容

### 1. 应用骨架

- 技术栈：**Electron 37 + electron-vite 4 + React 19 + TypeScript + Tailwind CSS 4 + Zustand 5**
- 三端结构：`src/main`（主进程）、`src/preload`（contextBridge 桥）、`src/renderer`（React 界面）、`src/shared`（跨进程共享类型与预设）

### 2. AI 配置（参考 PI-Desktop providers 设计）

- 首次启动进入 **AI 配置引导页**（SetupPage），保存后进入主页面；之后启动直接进主页面
- 配置字段：配置名称 / Provider / API Key / Base URL / 模型
- 内置 Provider 预设：OpenAI、Anthropic、DeepSeek、Google Gemini、自定义（OpenAI 兼容），选择预设自动填充 Base URL 与推荐模型
- 支持**多套配置**：主页面右上角打开配置管理弹窗（ConfigManager），可新增 / 编辑 / 删除 / 一键切换"使用中"
- 第一条保存的配置自动设为激活；删除激活配置时自动顺移到最早一条

### 3. 持久化

- 存储文件：`~/.easyCode/config.db`（SQLite，WAL 模式）
- 使用 Electron 内置 Node 的 **`node:sqlite`**（DatabaseSync），零原生编译
  - 注：未选 better-sqlite3，因本机无 Visual Studio C++ 工作负载，源码编译失败
- 表结构：
  - `ai_configs`：id / name / provider / api_key / base_url / model / is_active / created_at / updated_at
  - `app_meta`：key / value（预留）

### 4. 主页面

- 左上角两个 tab：**协作**、**编排**（当前为占位页，功能待后续版本）
- 右上角：当前激活配置展示（名称 · 模型）+ 配置管理入口

### 5. 打包

- 根目录 **`打包.bat`**：检查依赖 → 构建 → electron-builder 打包 Windows 产物
- 产物（`release/`）：`easyCode Setup 0.1.0.exe`（NSIS 安装包）、`easyCode-0.1.0-win.zip`（免安装包）、`win-unpacked/`（免安装目录）
- `.npmrc` 配置 `electron_mirror`（npmmirror），bat 内置 `ELECTRON_BUILDER_BINARIES_MIRROR`，解决国内下载 GitHub 二进制被重置的问题

## 已知事项

- electron 的 install.js 曾出现解压静默失败（dist 只剩 locales/）：用 PowerShell `Expand-Archive` 解压 `%LOCALAPPDATA%\electron\Cache\<hash>\electron-v*-win32-x64.zip` 手动替换 dist 修复
- `node:sqlite` 带 ExperimentalWarning 提示，不影响功能
- 安装包未做代码签名，Windows 可能提示 SmartScreen 警告
- 「协作」「编排」两个 tab 为占位内容，需求待定
